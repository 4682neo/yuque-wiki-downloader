# yuque-wiki-downloader

语雀知识库批量下载用户脚本，基于 Tampermonkey / ScriptCat 运行，直接在语雀知识库页面中批量导出文档到本地。

## 功能

- 自动递归展开知识库目录树
- 批量下载语雀知识库下的文档
- 保留目录结构，导出为 Markdown
- 支持单篇文档下载
- 在语雀页面内直接运行，无需命令行环境

## 安装

1. 安装用户脚本管理器（任选其一）：
   - [Tampermonkey](https://www.tampermonkey.net/)（油猴）
   - [ScriptCat](https://scriptcat.org/)（脚本猫）
2. 安装本仓库中的用户脚本：
   - 打开脚本文件，复制全部内容，在脚本管理器中新建脚本并粘贴保存；或
   - 通过脚本管理器直接导入 `.js` 文件
3. 在脚本管理器中确认该脚本已启用。

## 使用方法

1. 登录语雀，打开目标知识库页面（`www.yuque.com`）。
2. 在知识库首页，脚本会注入操作入口（按钮 / 面板）。
3. 按提示选择：递归展开目录 → 扫描目录 → 批量导出。
4. 下载的 Markdown 文件会保存到浏览器默认下载目录，目录结构按知识库层级保留。

## 配置说明

脚本运行前可能需要以下信息（视脚本实现而定）：

| 配置项 | 说明 |
| --- | --- |
| 知识库 URL | 目标语雀知识库地址，可从浏览器地址栏获取 |
| 导出格式 | Markdown / ZIP（含图片） |
| 请求间隔 | 批量导出时的请求间隔，避免触发频率限制 |

## 兼容性

- Tampermonkey（Chrome / Edge / Firefox）
- ScriptCat（Chrome / Edge）
- 需已登录语雀账号，并具备目标知识库的访问权限

## 注意事项

- 请遵守语雀服务条款，仅下载你有权限访问的内容。
- 批量导出请控制请求频率。语雀对请求频率有限制，过快可能被限流。
- 脚本依赖语雀页面结构，语雀前端更新后可能失效，需自行调整。
